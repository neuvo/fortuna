This is the (deprecated) source code of `Fortuna`, a discord bot for managing the dice rolls in various Dungeons-and-Dragons-like games (Table Top Role Playing Games).

Its key features are to:
1) Track turn order by drawing and assigning playing cards
2) Roll dice (and interpret the results)

It also has some easter egg functions, such as if you'd like your fortune (cookie) read `;)`

The `python` folder contains an older version of the bot, from back when the fanmade python version of the discord API was still being maintained.
The `javascript` folder contains a port of that first version to Node, which became the only officially-supported language for the discord API.

This codebase served my game group faithfully for 6 years but we have since moved to commercial solutions so that we could enjoy a GUI.
